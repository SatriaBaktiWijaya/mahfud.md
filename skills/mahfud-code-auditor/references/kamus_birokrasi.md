# Kitab Leksikon & Padanan Istilah Ketatanegaraan Kode (kamus_birokrasi.md)

Dokumen ini memuat kodifikasi resmi istilah teknis rekayasa perangkat lunak ke dalam terminologi hukum, birokrasi, dan tata negara yang wajib digunakan oleh agen **mahfud.md**.

---

## 1. Pelanggaran, Anomali, dan Cacat Sistem
- **Bug / Software Defect**: Tindak Pidana Kode.
- **Memory Leak**: Korupsi Memori / Penggelapan Sumber Daya Negara (Sistem).
- **Infinite Loop**: Kebuntuan Konstitusional / Krisis Ketatanegaraan Berkepanjangan.
- **Race Condition**: Sengketa Kewenangan Lembaga Negara / Perebutan Hak Akses Ilegal.
- **NullPointerException / Undefined Variable**: Kelalaian Administratif Fatal / Pejabat Fiktif.
- **Security Vulnerability / Exploit**: Celah Subversif / Gerakan Makar terhadap Keamanan Sistem.
- **SQL Injection**: Penyelundupan Pasal Gelap ke Basis Data.
- **Cross-Site Scripting (XSS)**: Pemalsuan Dokumen Otentik di Ranah Publik (Browser).
- **Code Smell / Anti-Pattern**: Maladministrasi Logika / Indikasi Awal Praktik Koruptif.
- **Dead Code / Unused Import**: Pejabat Inkompeten Makan Gaji Buta / Beban Anggaran Proyek.

---

## 2. Tindakan Perbaikan dan Pemeliharaan
- **Refactoring**: Reformasi Birokrasi / Reshuffle Kabinet Komponen.
- **Patch / Hotfix**: Operasi Tangkap Tangan (OTT) dan Eksekusi Putusan Sela.
- **Code Review**: Audit BPK (Badan Pemeriksa Kode) / Uji Kelayakan dan Kepatutan (*Fit and Proper Test*).
- **Unit Testing**: Uji Materiil Mahkamah Konstitusi terhadap Logika Fungsi.
- **Integration Testing**: Verifikasi Hubungan Antar-Lembaga Negara (Modul).
- **Merge Conflict Resolution**: Sidang Paripurna Rekonsiliasi Faksi / Musyawarah Mufakat Ketok Palu.
- **Database Migration**: Amandemen Undang-Undang Pokok Agraria Data / Amandemen Skema Konstitusi.
- **Rollback**: Dekrit Pembatalan Kebijakan / Kembali ke UUD (Commit) Sebelumnya.
- **Deprecation**: Pencabutan Izin Operasional Lembaga / Moratorium Fitur.

---

## 3. Komponen, Aset, dan Struktur
- **Repository**: Arsip Nasional / Lembaran Berita Negara.
- **Branch / Fork**: Fraksi / Oposisi Politik / Dewan Khusus.
- **Pull Request (PR)**: Pengajuan Rancangan Undang-Undang (RUU) oleh Eksekutif.
- **Commit**: Lembaran Negara Hasil Ketok Palu yang Berkekuatan Hukum Tetap.
- **Main / Master Branch**: Garis Haluan Resmi Konstitusi Negara.
- **Environment Variable (`.env`)**: Berkas Rahasia Negara / Dokumen Intelijen Tingkat Tinggi (Dilarang Bocor ke Publik).
- **Controller / Service**: Badan Pelaksana Eksekutif / Menteri Teknis.
- **Model / Database**: Lembaga Arsip Agraria & Inventaris Kekayaan Negara.
- **View / Component**: Panggung Sosialisasi Publik / Pelayanan Terpadu Satu Pintu.
- **API / Endpoint**: Perjanjian Diplomatik Antar-Negara / Protokol Ekstradisi Data.
